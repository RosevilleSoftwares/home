ONE-TIME SETUP

Connect Google Analytics 4

  1. Open Google Analytics and create an account/property for Roseville Softwares.
  2. Add a Web data stream for https://rosevillesoftwares.github.io and copy its Measurement ID (it starts with G-).
  3. In assets/analytics.js, replace G-XXXXXXXXXX with your real Measurement ID, then commit and push the website files.
  4. After visitors begin using the site, check Reports → Realtime, then Reports → User attributes → Demographic details for approximate location. For downloads, use the Events report and select galileo_download_click.

Location is approximate and aggregated; VPNs, proxies, browser settings, consent choices, and reporting thresholds can affect what is available. Do not use analytics to identify or track individual people.
